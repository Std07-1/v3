# `tools/_archive/` — інструменти платформи, виведені з ужитку

Тут лежать інструменти, які платформа більше не запускає і не імпортує. Історію збережено
свідомо (`git log --follow tools/_archive/<файл>`): щоб рішення можна було перевірити, а не щоб
ними користуватися.

| Файл | Виведено | Чому |
|---|---|---|
| `htf_rebuild_from_fxcm.py` | 23.09.2026, ADR-0095 S5b (рішення власника; план — ADR-0054 §1.6 п.2 і §3.1, засів п.4) | Писав у SSOT нативні H4/D1 FXCM (`src=history`), а H4/D1 будуються лише з M1 (ADR-0002, ADR-0023, ADR-0095 §2 варіант C). `rewrite_range` переписував part-файли напряму, повз писар SSOT (`JsonlAppender`) і його перевірку сезонної сітки |
| `htf_tail_sync_from_fxcm.py` | те саме | Хвіст H4/D1 з FXCM через той самий `rewrite_range` — той самий обхід |

- Запуск будь-якого з них дає `HTF_TOOL_RETIRED` (SystemExit). Каталог без `__init__.py`,
  жоден модуль платформи звідси не імпортує; нічого звідси не входить у CI, гейти чи runtime.
- Їхні тести (`tests/test_htf_rebuild.py`, `tests/test_htf_tail_sync.py`, розділ `rewrite_range`
  у `tests/test_repair_dedup_integrity.py`) прибрано тим самим комітом — вони лишились у git-історії.
- H4/D1 після ремонту дір M1 перебудовує `tools/rebuild_from_m1.py` (сезонна сітка ADR-0095);
  історію H4/D1 під сезонну сітку — інструмент S7 ADR-0095 (`purge_derived_window`).
