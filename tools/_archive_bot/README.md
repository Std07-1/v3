# `tools/_archive_bot/` — архів інструментів зовнішнього AI-клієнта

Тут лежать одноразові скрипти, патчі та діагностика, написані для бота Арчі
(`trader-v3`, окремий репозиторій) у часи, коли він і платформа жили в одному дереві.

**Платформа їх не використовує і не імпортує** — це історія, збережена свідомо
(ADR-0090 S5, owner-рішення 2026-09-06 «в архів їх всі»).

- Усі шляхи всередині вказують на `/opt/smc-trader-v3` — робочий каталог бота на VPS.
- Підкаталог `_archive_patches/` лишається поза git (`.gitignore`) — це локальний архів
  одноразових патчів, він ніколи не був у репозиторії.
- Активні інструменти платформи лишились у `tools/` (deploy, exit gates, repair,
  `diag/` для UDS/Redis/SMC платформи).
- Нічого звідси не запускається у CI, гейтах чи runtime.

Якщо скрипт знадобиться боту — його місце в репозиторії бота, не тут.
