## 1. Контекст

`aione-watchdog.sh` (root, systemd-таймер щохвилини) з липня стежить за VPS і шле в Telegram через `aione-alert.sh`.
Три проблеми:

1. **Не той канал.** Токен у `/etc/aione-alerts/env` був ботом Арчі («Ментор»): системні події говорили голосом
   агента. 29.09 власник створив окремого бота «Monitor» і замінив токен (зроблено до цього ADR).
2. **Шум.** Журнал `/var/log/aione-alerts.log` за 86 днів: 426 сповіщень про SSH-вхід — усі 426 з домашньої мережі
   власника його ключем (40 лише 28.09, переважно сесії агента); 38 однакових «тиск на swap» за один день 04.08
   (повтор кожні 10 хв, поки стан тримався); сплеск процесів без відповіді «хто». Реальних подій — одиниці.
3. **Поза git.** Скрипти існують лише на сервері: правки без історії, без тестів, без відкату з git.

Heartbeat приходить у довільний час доби (24 год від попереднього), а власник живе за Прагою (UTC+2), не Києвом.

## 3. Рішення

### 3.1 Канал і місце в git
Системні події йдуть окремим ботом (токен і чат — лише `/etc/aione-alerts/env`, root 600). Скрипти й юніти живуть у
`ops/vps/`; на сервер ставляться `install` з checkout-а платформи (ранбук), встановлена копія = файл з git.
Мітки IP і ключів лишаються поза git (`/etc/aione-alerts/known_ips`, `known_keys`).

### 3.2 SSH-входи
- **Свій** — ключ є в `known_keys` **і** адреса в `known_ips`: без повідомлення, лише лічильник для ранкового звіту.
- **Твій ключ з нової мережі** — повідомлення (не тривога): «твій ключ, але мережа невідома — якщо в дорозі, ок».
- **Невідомий ключ або вхід без ключа** — тривога одразу.

### 3.3 Ресурси: зміна стану, а не повтор
load, пам'ять, swap, кількість процесів: проблема **починається**, коли поріг перевищено `RES_ENTER_TICKS` (2) тіки
поспіль — одне повідомлення з винуватцями (топ процесів за CPU/RSS/кількістю). **Закінчується** після
`RES_CLEAR_TICKS` (5) нормальних тіків поспіль — одне повідомлення з тривалістю. Поки триває — нагадування не частіше
ніж раз на `RES_REMIND_S` (6 год). Диск — як раніше (самолікування журналом).

### 3.4 Падіння
FATAL програми supervisor-а — з останніми рядками її stderr (рядки, схожі на секрети, маскуються); відновлення —
з тривалістю простою. Так само для systemd-служб (inactive/failed → active). Ролі програм оновлено.

### 3.5 Ранковий звіт
Один раз на добу о `REPORT_HOUR` (9) за `REPORT_TZ` (Europe/Prague) замість heartbeat-а: сервер (аптайм, load,
пам'ять, диск), платформа (стан програм, останній нічний settle), бекап Арчі, SSH за добу (своїх / інших), бани,
події за добу (що вже надсилалось) і зведення відвідувачів ADR-0105 (`tools.visitors.report`, від `smc`). Доставлений
звіт обнуляє денні лічильники. Окремий cron і Python-відправник зведення відвідувачів (ADR-0105 S3) прибрано.

### 3.6 Відправник
Текст довший за 4000 символів обрізається (Telegram відхиляє >4096, а відхилене повідомлення watchdog повторював
би щохвилини безкінечно).

### 3.7 Команди власника (03.10)
Власник хоче дивитися відвідувачів і стан не лише вранці. Бот «Monitor» відповідає на команди з чату `ALERT_CHAT_ID`
(інші чати ігноруються): `/visitors [днів]` — зведення ADR-0105 за N днів (типово 7, 1–365), `/status` — розділи
ранкового звіту зараз, без обнулення лічильників; решта — список команд. `aione-commands.sh` читає `getUpdates` (без
довгого опитування, раз на тік watchdog-а — відповідь до хвилини; нового сервісу нема), watchdog відповідає через
`aione-alert.sh`. `offset` рухається лише після відповідей на всі команди пачки (повтор може продублювати відповідь, але
не загубити команду); перший запуск лише засіває `offset` (старі повідомлення не виконуються) і реєструє меню команд.
Пісочниця watchdog-а мусить вимикати команди (`COMMANDS=/nonexistent`): `getUpdates` з offset підтверджує повідомлення
на боці Telegram, і пісочниця «з'їла» б команди справжнього watchdog-а.

## 4. Наслідки
- Телефон дзвонить лише на те, що вимагає уваги; щоденна картина — одним повідомленням уранці.
- Затримка першого сповіщення про ресурси — до 2 хв (хвилинні сплески більше не будять).
- Watchdog з git: зміни через коміт і `install`, відкат — попередня версія з git.

## 5. Rollback
`git show <попередній коміт>:ops/vps/aione-watchdog.sh | sudo install -m 755 /dev/stdin /usr/local/sbin/aione-watchdog.sh`
(так само `aione-alert.sh`); до першого встановлення з git — копія `/usr/local/sbin/aione-watchdog.sh.pre-adr0106`.
Токен бота Арчі — `/etc/aione-alerts/env.bak.*`.
